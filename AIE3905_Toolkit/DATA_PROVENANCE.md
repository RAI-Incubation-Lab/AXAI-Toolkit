# Data Provenance and Redistribution

Each case study identifies its Kaggle source in its local README. Kaggle datasets can have dataset-specific licences, access conditions, and updates. The toolkit code is MIT licensed; the datasets are not relicensed by this repository.

Before redistributing a case-study folder, verify the dataset's current Kaggle licence and attribution requirements. If redistribution is not permitted or impractical, include a small licence-permitted fixture for automated tests and provide a documented download procedure for the full dataset.

The Bitcoin minute-level CSV is deliberately excluded because of its size. Its folder contains a download and schema-verification script.
